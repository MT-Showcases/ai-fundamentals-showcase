# AI Fundamentals Showcase — Asset Delivery Map

Fonte unica per naming e upload media.

## Naming Convention (obbligatoria)

Base folder per capitolo:
`media/chXX-<chapter-slug>/`

### Asset di sezione
`media/chXX-<chapter-slug>/sec-YY/`
- `video.mp4`
- `infographic.png`
- opzionali:
  - `podcast.mp3`
  - `notes.pdf`

### Asset di capitolo (finali)
`media/chXX-<chapter-slug>/`
- `video.mp4` (video completo capitolo)
- `podcast.mp3`
- `infographic.png`
- `handout.pdf`
